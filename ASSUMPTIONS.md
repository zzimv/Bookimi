# Допущения

1. Шаг 1 (тест узнаваемости) не прогнан: нужны реальные фото детей с согласиями родителей и GPU в РФ.
   Подготовлены протокол, сцены, скрипт и шаблон согласия. До прогона модель по умолчанию — Qwen-Image-Edit.
2. Реестр образов — GitHub Container Registry (ghcr.io); деплой по SSH в /opt/bookimi.
3. Next.js 15, Prisma 6, pg-boss 10. Prisma-миграция `0001_init` создаётся командой `prisma migrate dev`
   при первом локальном запуске (движки Prisma недоступны в среде, где писался код).
4. Обложки — собственные простые SVG-иллюстрации до загрузки настоящих обложек в админке.
5. Шрифты Nunito (заголовки) и Manrope (текст) — self-hosted через пакеты @fontsource.
6. Фильтр «пол» показывает все сюжеты: все 5 сюжетов подходят мальчикам и девочкам. Поле `gender` в БД — задел.
7. Сюжеты без повода показываются на всех страницах поводов после сюжетов этого повода.
8. Добавлены возрастные посадочные `/vozrast/5-7-let` и `/vozrast/8-9-let` в дополнение к `/vozrast/2-4-goda`.
9. Юридические тексты — шаблоны, которые должен проверить юрист. Реквизиты подставляются из настроек.
10. Отзывы на сайте показываются только из БД после модерации; пока их нет, секция скрыта.
11. CSP пока разрешает inline-скрипты (нужны Next.js); на шаге 7 заменяется на nonce.
12. Срок обращения по браку — 14 дней после получения; срок возврата денег — 10 дней.
13. Заказ, по которому покупатель нажал «Я оплатил(а)», не отменяется автоматически через 24 часа — его
    решает оператор (чтобы не отменить оплаченный заказ).
14. Деплой: `prisma migrate deploy` выполняется после `up -d`, как в ТЗ; миграции пишутся обратно совместимыми.

## Шаг 1, вторая итерация

15. Фото реальных детей из интернета для теста не используются. «Чужие» дети в слепой оценке —
    синтетические лица, сгенерированные моделью (foils.py); реальные дети — только с согласием родителей.
16. Исхожу из того, что у вас есть согласие родителя Марка на использование его фото в тесте.
    Фото не добавлено в репозиторий и архив.
17. Улучшение фото — только классическое (шумоподавление, контраст, резкость, кадр). ИИ-реставрация
    лица выключена по умолчанию: она дорисовывает черты и снижает сходство.
18. Тестируются 5 стилей; в продукт идут 3 лучших по узнаваемости. Под «Васнецовым» понят
    Юрий Васнецов (детская книга), не Виктор.
19. Имена художников в промптах и на сайте не используются — стили описаны техникой и палитрой.
20. «Обучение» системы — подбор параметров конвейера по метрике ArcFace, без дообучения модели на лице
    ребёнка.
21. Версии моделей: Qwen/Qwen-Image-Edit-2511 (QwenImageEditPlusPipeline) и
    kandinskylab/Kandinsky-5.0-I2I-Lite-sft-Diffusers (Kandinsky5I2IPipeline). Меняются переменными
    QWEN_MODEL и KANDINSKY_MODEL. На реальном GPU скрипты ещё не запускались.
22. Отзывы на сайте — только настоящие, с разрешением автора: импорт из data/reviews.json.
23. Тексты оферты, политики и согласий можно заменить из админки (настройка legal.<ключ>) без выкладки.

## Шаги 4–7

24. Порядок квиза — как согласовано: анкета без фото → сказка → подтверждение → согласия → фото → вход по коду → превью.
    Контакт подтверждается кодом: без этого лимит «1 превью на контакт» обходился бы любым адресом.
25. Текст сказки — YandexGPT; имя ребёнка не отправляется, подставляется у нас с падежами (src/lib/declension.ts).
    Для 5 готовых сюжетов модель следует плану из 12 разворотов, описания сцен для иллюстраций — проверенные.
26. Пока ключи не подключены, работает демо-генерация (шаблонный текст и SVG-иллюстрации) — переключение в админке.
27. Prisma работает без бинарных движков (WASM + драйвер pg); миграции применяет scripts/migrate.mjs,
    совместимый с таблицей _prisma_migrations.
28. Вход по телефону требует SMS-провайдера (SMS_PROVIDER: smsc или sms.ru); без него — вход по email.
29. Сервис СБП-QR для самозанятых не выбран — сделан универсальный адаптер (PAYMENT_SBP_*); конкретный API
    подключается под выбранный сервис. Чеки НПД по умолчанию — ручной режим: оператор вставляет ссылку из «Мой налог»
    (или автоматически, если чек выдаёт платёжный сервис либо подключён партнёр ФНС).
30. Себестоимость генерации считается по цене часа GPU из настроек (300 ₽ — ориентир, сверить с прайсом Yandex Cloud).
31. Блок книги для печати: страница посвящения + 24 страницы сказки + финальная страница = 26 страниц; корешок
    и загибы обложки — по типовым значениям, сверить с шаблоном типографии.
32. Допы «ростомер, наклейки, постер, упаковка» передаются в типографию списком; макеты этих изделий типография
    делает по файлам книги — либо добавить свои шаблоны позже.
33. «Клон голоса родителя» — выключен до проверки юристом и лицензии модели; «Читаю сам» — работает.
34. Отзывы — только настоящие; выдуманные не создаются. Рейтинг в разметке schema.org — только по опубликованным отзывам.
