# Контент-движок БУКИМИ: архитектура и правила

Профили аудиторий — `PROFILES.md` / `src/content/profiles.ts`. Контракты — `src/content/types.ts`.

## Схема

```
profiles.ts (аудитории, сегменты, поводы, id стилей)
   │
   ├── plots/{kids,teens,adults,pets}.ts ── Plot: 12 разворотов, голос, стили, тема, крючки поводов
   ├── text-styles.ts ───────────────────── TextStyle: системный промпт YandexGPT для каждого голоса
   ├── art/{kids,teens,adults,pets}.ts ──── ArtStyle (промпт Qwen + демо-палитра), DemoTheme, рисовальщик героя
   ├── moods.ts + art/mood.ts ───────────── Mood: добавка к промпту + тонировка демо
   └── occasions.ts ─────────────────────── общие крючки поводов, {ПОВОД}
              │
              ▼
   registry.ts — getPlots, plotBySlug, plotsForOccasion, hooksFor, applyOccasion,
                 textStyle, artStyle, mood, segmentsFor, validateContent
   art/index.ts — ART_STYLES, themesByKey, heroDrawer (безопасно для клиента)
   art/render.ts — renderDemoSpread / renderDemoCover (SVG без GPU)
   answers.ts — AnswersV2 (анкета 4 аудиторий), ContactV2
              │
              ▼
   анкета и каталог (сайт) · gen/text.ts (YandexGPT, демо) · gen/image.ts (Qwen, демо-SVG) · tools/demo
```

`registry.ts` содержит системные промпты и планы сюжетов — **только сервер и демо-стенд**. В клиентские
компоненты — `art/index.ts`, `art/render.ts`, `answers.ts`, `profiles.ts` и проекции из серверных props.

## Метки (имя никогда не уходит в ИИ)

Подстановка — `fillTags(text, ctx)` в `src/lib/declension.ts`; проверка — `checkTags` в `src/content/tags.ts`.
Падежи: `им род дат вин тв пр`.

| Метка | Что подставляется |
|---|---|
| `{ГЕРОЙ.дат}`, `{ГЕРОЙ}` | имя героя (для питомца — кличка) |
| `{ЛАСКОВО.им}` | домашнее имя (если нет — имя) |
| `{ДОП1.вин}` … `{ДОП3.тв}`, `{ДОП1}` | доп. герои по порядку анкеты |
| `{ДОПЫ.дат}` *(новое)* | все доп. герои списком: «Ане, Пете и Маше» |
| `{Р:м\|ж}`, `{Р:м\|ж\|ср}` | форма по полу героя; средний род — только если указан |
| `{Р1:м\|ж}` … `{Р3:…}` *(новое)* | форма по полу доп. героя 1..3 |
| `{МН:один\|много}` *(новое)* | по числу доп. героев (1 / больше 1) |
| `{ПОВОД}`, `{ПОВОД.дат}` | повод словом для текста (`OCCASION_WORDS` в occasions.ts: «новоселье», «годовщина», «выход на пенсию») или текст «своего повода» (не склоняется); в начале фразы/цитаты — с заглавной |
| `{ВОЗРАСТ}` *(новое)* | «5 лет», «3 года» — только где возраст точно известен |
| `{ГРУППА.дат}` | дети группы (без героя) списком: «Ане, Пете и Маше»; > 8 имён — продолжение следующими фразами («И с Соней, Верой и Гошей — тоже.») |
| `{ДРУГ1.тв}` … `{ДРУГ14.*}` | слот: ребёнок группы; если детей больше, чем слотов, — несколько подряд («Ваня, Петя и Оля») |
| `{РД3:нашёл\|нашла\|нашли}` | форма по слоту: мальчик \| девочка \| несколько детей |
| `{МН_ГРУППЫ:пришёл\|пришла\|пришли}` | по детям группы: один мальчик \| одна девочка \| много |
| `{ВОСПИТАТЕЛЬ.дат}`, `{ВОСПИТАТЕЛЬ2.*}`, `{ВОСПИТАТЕЛИ.*}`, `{РВ:м\|ж}`, `{РВ2:…}` | взрослые группы (1..3), имя-отчество склоняется целиком: «Марии Ивановне», «Ивану Петровичу» |
| `{ПЕРЕКЛИЧКА}` | все имена через « · », герой посередине — разворот «Наш класс» / «Наша группа» |

**Аудитории.** Подростки и взрослые — как дети. **Пары:** второй главный герой — `{ДОП1.*}` (роль `partner`,
`extras.min = 1`), его род — `{Р1:…}`. **Книги «от детей/внуков/коллег»:** дарители — доп. герои, вместе — `{ДОПЫ.*}`,
число — `{МН:…}`. **Питомцы:** герой — питомец (`{ГЕРОЙ.*}`, род — по полу питомца: boy/girl = он/она),
хозяева — `{ДОП1.*}`, `{ДОП2.*}` (роль `owner`). **«Свой вариант»** (дерево, робот, машина) — роль `custom`,
род `boy | girl | n` (средний для «облака»), без рода — угадывается по имени. Отчества — только у взрослых группы.

**Правила текста:** `нашёл{Р:|а}` даёт «нашёла» — пишите `{Р:нашёл|нашла}` (validateContent ловит).
Если текст ссылается на `ДОПn` / `Рn` / `ДОПЫ`, у сюжета `extras.min ≥ n`. В стихах (`verse: true`) строки
разделяются `\n`; имя (1–5 слогов) и `{ПОВОД}` — **только в отдельной строке-обращении вне метра** («— {ГЕРОЙ.им}!»,
«Спи, {ЛАСКОВО.им}.», «{ПОВОД}!» — кроме метки не больше одного слова), не больше 4 меток имени на книгу; формы
`{Р:…|…}` — с равным числом слогов; «наш герой» о девочке нельзя (validateContent ловит). Рядом с `{ПОВОД}` — без
прилагательных и прошедшего времени по роду («Пусть этот праздник — {ПОВОД} — будет…»).
**Доп. герои в детских книгах** (без ИИ) — `src/lib/gen/extras.ts`: каждому ≥ 3 готовые фразы (начало, середина, финал) на
разных разворотах, по роли; в стихах — двустишие без форм рода и имя строкой-обращением («— Кошка {ДОП1.им}!»).
Предлог перед подставленным именем fillTags правит сам: «о/об» («об Ане», «о Юле»), «с/со» («со Львом»), «к/ко».
Название с `[Имя]` — только через `src/content/title.ts` (`titleTemplate` / `titleForCatalog`): падеж по предлогу.
Сцены (`scene`, `coverScene`, сцены крючков) — только по-английски и без имён.

**Поводы.** Любой сюжет дарится на любой повод: `hooksFor(plot, повод)` берёт `plot.occasionHooks[повод]` →
`plot.occasionHooks.default` (обязан содержать `{ПОВОД}`) → общий крючок из `occasions.ts`. Пустой крючок
`{opening:"", closing:""}` — «сюжет уже об этом поводе». `applyOccasion` дописывает opening в разворот 1,
closing — в разворот 12, сцены — к сценам. Сюжеты в стихах обязаны давать свои крючки.

**Каталог повода** — `plotSections(повод, аудитория, {segment?, age?})` → `{ core, custom: true, fits, fitsTitle,
others, hiddenCount, strong, customFirst }`. core — написан для повода (`plot.coreOccasions` или пустой крючок),
fits — повод в `occasions` или свой крючок (к Рождеству/Старому НГ — ещё новогодние), остальное — generic.
Показ: `customFirst ? [«Своя история», core, fits, others] : [core, «Своя история», fits, others]`; fits — под заголовком
«Тоже подойдут — впишем ваш повод». Сильная тема (`STRONG_OCCASIONS`) прячет generic. «Без повода» и «свой» —
«Своя история» первой, затем все. `plotsForOccasion` — старый плоский список (core → fits → generic). Матрица — `OCCASIONS-MATRIX.md`.
Логика разделов — `sectionsOf` в `sections.ts` (безопасно для клиента: анкета и демо считают по проекции `sectionPlot(plot)`);
`plotSections` — обёртка над ней, поэтому сайт, страница повода и анкета показывают книги в одном порядке.

## Группа (детсад, класс, команда)

`plot.group = { min, max, label: "группа"|"класс"|"команда", includeAdults?: { roles, max ≤ 3 } }` — размер **вместе с
героем**, max ≤ 40 (детсад — 30: старшие и подготовительные группы в России обычно 20–30 детей; класс — 40).
Анкета: `answers.group = { members: {name, gender?, photo?, description?}[] (без героя, до max − 1), adults: {name, role, gender?}[] }`.

- **Слоты.** `{ДРУГn}` (n = 1..14) живёт в одном развороте, номера идут по порядку разворотов, слотов в книге —
  `min(14, max − 1)`. Распределение (`distributeMembers`): детей ≤ слотов — слот n = ребёнок n, лишние слоты выпадают;
  детей больше — слоты получают подряд идущие кучки (≤ 3 имени при 40). Так каждый назван, и никто — дважды, пока
  не прозвучали все. Формы по слоту — `{РДn:м|ж|мн}` (третья форма обязательна, если детей бывает больше слотов).
- **Блоки** `[[?УСЛОВИЕ: текст || иначе]]` (без вложенности): `ДРУГn` (у слота есть свои дети), `ГРУППА`,
  `ГРУППА>8`, `ГРУППА<9`, `ВОСПИТАТЕЛЬn`, `ВОСПИТАТЕЛИ`. Метки детей — только в блоках `ДРУГn`/`ГРУППА`
  (группа может быть пустой), метки взрослых — только в `ВОСПИТАТЕЛЬn` с веткой «иначе» без имени. В стихах блок —
  целые строки; выпавший блок убирает строку.
- **Ведомость.** Группа больше 9 — разворот с `{ПЕРЕКЛИЧКА}` (общая фотография, герой в центре).
- **Сцены.** `{GROUP}` → «a group of 14 kindergarten children», `{GROUP_ADULTS}` → «a kind kindergarten teacher» —
  `applyGroupScenes(plot, spreads, детей, взрослых)`. В `coverScene` меток нет. Демо — `renderDemoSpread({ crowd:
  crowdLooks(members, adults), crowdLayout: "around" | "photo" })`: до 40 фигур рядами, мимо героя.
- **ИИ.** В бриф — план, раскрытый под размер группы (`resolveGroupBlocks`), без имён; имена детей в свободном тексте →
  «друг из группы», воспитатели → `{ВОСПИТАТЕЛЬn}` (`personsOf` в redact.ts); в картинки — «a child from the group».
- **Стихи.** Имена детей и взрослых — только строками-обращениями («— {ДРУГ3.им}!»); лимит 4 касается имени героя.

аудитории. Стили картинок: владелец каждого id — `ART_STYLE_OWNERS`; сюжет может рекомендовать любой id из `ART_STYLE_IDS`.

## Definition of Done для контент-агентов

- Сюжеты: дети ≥ 9 по трём сегментам (вкл. 5 перенесённых, slug не менять), подростки ≥ 5, взрослые ≥ 5
  (все 4 сегмента), питомцы ≥ 4 (собака и кошка). В каждом ровно 12 разворотов, крючки главных поводов + `default`.
- Художники: все свои стили из `ART_STYLE_OWNERS` и темы из `DEMO_THEME_KEYS`, рисовальщик героя. Настроения: ≥ 8.
- `validateContent()` без ошибок; `npx tsc --noEmit`; `npx vitest run tests/content.test.ts` — зелёные.
- Оригинальный текст; без имён живых авторов и художников, франшиз, брендов; запреты сегментов.
