# Поводы × аудитории: какие книги показываем

Сгенерировано из `plotSections(повод, аудитория)` (`src/content/registry.ts`). Перегенерировать после новых сюжетов.

**Правила порядка**
- **core** — сюжет написан для повода (`plot.coreOccasions` или пустой крючок `{opening:"",closing:""}`);
  **fits** — повод вплетается естественно (есть в `plot.occasions` или есть свой крючок; к Рождеству и
  Старому Новому году — ещё книги про Новый год); **generic** — только общий крючок.
- Порядок показа: есть core → `core`, «Своя история», «Тоже подойдут — впишем ваш повод» (`fits`), `others`;
  нет core → «Своя история» первой.
- ★ сильная тема (выпускные, первый класс, рождение брата/сестры, свадьба, годовщина, пенсия, появление
  питомца, Новый год, день рождения): generic скрыты (`hiddenCount`). Если нет ни core, ни fits — ничего не
  прячем (иначе каталог пуст): это пробел контента.
- «Без повода» и «Свой повод» — «Своя история» первой, затем все сюжеты (с `bez` в occasions — выше).
