# Витрина «Фото → иллюстрация» на главной

Сейчас на главной показан **пример**: демо-отрисовка одного героя в трёх стилях и пустая рамка «Ваше фото».
Чтобы показать настоящую пару «фото → иллюстрации»:

1. Получите **письменное согласие** семьи (или взрослого героя) на публикацию фото и иллюстраций на сайте.
   Для детей — согласие законного представителя. Храните скан согласия у себя.
2. Положите в эту папку файлы, например:
   - `masha.jpg` — исходное фото (квадратное, 800×800, лицо крупно);
   - `masha-akvarel.jpg`, `masha-lubok.jpg`, `masha-klassika.jpg` — иллюстрации из готовой книги (квадрат, 600×600).
3. Создайте здесь файл `showcase.json`:

```json
{
  "consent": true,
  "photo": "/showcase/masha.jpg",
  "alt": "Маша, 5 лет — фото",
  "styles": [
    { "src": "/showcase/masha-akvarel.jpg", "title": "Воздушная акварель" },
    { "src": "/showcase/masha-lubok.jpg", "title": "Народная сказка" },
    { "src": "/showcase/masha-klassika.jpg", "title": "Добрая классика" }
  ]
}
```

Без `"consent": true` блок продолжит показывать пример. Не используйте фото из интернета и фото без согласия.
После замены файлов перезапустите сайт (или дождитесь обновления страницы — до 5 минут).
